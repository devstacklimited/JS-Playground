# JS Playground

A simple project to **learn and experiment with JavaScript (JS) and TypeScript (TS) concepts**.  
This repository contains small examples, exercises, and experiments to improve understanding of JavaScript and TypeScript features.


## 📚 Project Overview

This project includes:

- Core **JavaScript concepts** (variables, functions, objects, arrays, ES6 features)
- **TypeScript basics** (types, interfaces, enums, generics)
- Practice exercises for each concept
- Notes and examples for reference

This is a personal learning project and a sandbox for testing new ideas.


## 🚀 Getting Started

### Prerequisites

- Node.js (v14+ recommended)
- npm or yarn

### Installation

Clone the repository:

```bash
git clone https://github.com/devstacklimited/JS-Playground.git
```

```bash
cd js-playground
```
